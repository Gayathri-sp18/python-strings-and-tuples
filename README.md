## 🔤 String Operations

### 🔗 String Concatenation

The notebook demonstrates how multiple strings can be combined using the `+` operator.

Example:

```python
str1 = "Hello "
name = input("Enter your Name: ")

str2 = str1 + name
print(str2)
```

The exercise is extended by adding another string to create a complete sentence.

---

### 🔍 String Indexing & Slicing

The notebook explores different ways to access characters and portions of a string.

Examples include:

```python
str2[0]
str2[-1]
str2[:5]
str2[-11:]
str2[::-1]
```

Concepts demonstrated:

* First character access
* Last character access
* Extracting a portion from the beginning
* Extracting a portion from the end
* Reversing a string

---

### 🔎 Finding Text in a String

The `find()` method is used to locate Python within a string and extract the matching text.

```python
start = str2.find("Python")
print(str2[start:start + 6])
```

## 🛠️ String Methods

The notebook demonstrates commonly used Python string methods using the string:

```python
strM = "Python beginner tutorial"
```

### Methods Covered

| Method         | Purpose                           |
| -------------- | --------------------------------- |
| `upper()`      | Converts text to uppercase        |
| `lower()`      | Converts text to lowercase        |
| `capitalize()` | Capitalizes the first character   |
| `count()`      | Counts occurrences of a character |
| `replace()`    | Replaces specified text           |

Example:

```python
print(strM.upper())
print(strM.lower())
print(strM.capitalize())
print(strM.count("t"))
print(strM.replace("Python", "Machine Learning"))
```

## 📦 Tuple Operations

The notebook introduces basic operations using Python tuples.

Two tuples are created:

```python
t1 = (10, 20, 30)
t2 = (40, 50, 60)
```

### 🔗 Tuple Concatenation

```python
t_combine = t1 + t2
```

### 🔁 Tuple Repetition

```python
print(t_combine * 3)
```

### 🎯 Tuple Indexing

```python
print(t_combine[2])
```

### ✂️ Tuple Slicing

```python
print(t_combine[:3])
print(t_combine[-3:])
```
