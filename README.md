## 📌 About This Project

This repository contains my Python practice notebook focused on understanding and working with strings and tuples.

The notebook includes practical examples of:

* 🔗 String concatenation
* 🔍 String indexing
* ✂️ String slicing
* 🔄 Reversing strings
* 🔎 Finding text within strings
* 🛠️ Common string methods
* 📦 Creating and combining tuples
* 🔁 Repeating tuples
* 🎯 Tuple indexing and slicing

---

## 📚 Topics Covered

### 🔤 Strings

The notebook demonstrates:

```python
# String Concatenation
str2 = str1 + name
```

### 🔍 String Indexing & Slicing

Examples include:

```python
str2[0]
str2[-1]
str2[:5]
str2[-11:]
str2[::-1]
```

### 🛠️ String Methods

The notebook covers commonly used methods such as:

* `upper()`
* `lower()`
* `capitalize()`
* `count()`
* `replace()`

Example:

```python
strM.replace("Python", "Machine Learning")
```

---

### 📦 Tuples

The notebook also introduces basic tuple operations:

```python
t1 = (10, 20, 30)
t2 = (40, 50, 60)

t_combine = t1 + t2
```

It also demonstrates:

* Tuple concatenation
* Tuple repetition
* Tuple indexing
* Tuple slicing
